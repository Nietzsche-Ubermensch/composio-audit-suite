# Composio Audit Suite

Audit tooling for Composio-connected toolkits.

- **Dependency graphs** — map tool-to-tool dependencies across toolkits
- **Tool schemas** — pull and cache input/output schemas for every tool
- **Response schemas** — validate and document response shapes
- **Plan generator** — create execution plans across multiple toolkits
